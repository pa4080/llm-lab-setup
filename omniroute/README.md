# Omniroute Configuration Files

This directory contains generated configuration files for various clients from Omniroute model listings.

## Subdirectories

- **`copilot/`** – VS Code Copilot chat language models (`0-chatLanguageModels.json`)
- **`pi/`** – Pi.dev models (`0-pi-models.json`)

## Generation

All configurations are generated by running from the project root:

```bash
./scripts/omniroute-generate-config.sh
```

---

## Copilot Output Format

`copilot/0-chatLanguageModels.json`:

```json
[{
  "name": "LLaMA.cpp Local",
  "vendor": "omniroute",
  "apiKey": "${input:chat.lm.secret.-4b1abccd}",
  "baseUrl": "http://172.16.1.110:10005/v1/chat/completions",
  "models": [
    {
      "id": "auto/best-coding",
      "name": "auto/best-coding",
      "maxInputTokens": 666000,
      "maxOutputTokens": 384000,
      "supportsToolCalls": true,
      "supportsReasoningEffort": ["low", "medium", "high"],
      "vision": false,
      "inputModalities": ["text"]
    }
  ],
  "settings": {
    "caching": false,
    "seed": -1,
    "top_p": 1,
    "temperature": 0
  }
}]
```

### Copilot Field Mappings

| Copilot Field             | Omniroute Source                                                                |
| ------------------------- | ------------------------------------------------------------------------------- |
| `maxInputTokens`          | `max_input_tokens - max_output_tokens` or `context_length * 0.75`               |
| `maxOutputTokens`         | `max_output_tokens` or `context_length * 0.25`                                  |
| `supportsToolCalls`       | `capabilities.tool_calling` (default: `false`)                                  |
| `supportsReasoningEffort` | `capabilities.effort_tiers` or `["low", "medium", "high"]` for reasoning models |
| `vision`                  | `capabilities.vision` (default: `false`)                                        |
| `inputModalities`         | `input_modalities` or `["text", "image"]` if vision enabled                     |

## Pi Output Format

`pi/0-pi-models.json`:

```json
{
  "providers": {
    "llama-cpp-local": {
      "baseUrl": "http://172.16.1.110:10005/v1",
      "api": "openai",
      "apiKey": "${input:chat.lm.secret.-4b1abccd}",
      "models": [
        {
          "id": "auto/best-coding",
          "name": "auto/best-coding",
          "contextWindow": 1050000,
          "maxInputTokens": 666000,
          "maxOutputTokens": 384000,
          "input": ["text"],
          "supportsToolCalls": true
        }
      ]
    }
  }
}
```

### Pi Field Mappings

| Pi Field            | Omniroute Source                                                  |
| ------------------- | ----------------------------------------------------------------- |
| `baseUrl`           | `LOCAL_URL` with `/chat/completions` stripped                     |
| `contextWindow`     | `context_length`                                                  |
| `maxInputTokens`    | `max_input_tokens - max_output_tokens` or `context_length * 0.75` |
| `maxOutputTokens`   | `max_output_tokens` or `context_length * 0.25`                    |
| `input`             | `input_modalities` or `["text", "image"]` if vision enabled       |
| `supportsToolCalls` | `capabilities.tool_calling` (default: `false`)                    |

## Environment Variables

Required in project root `.env`:

- `LOCAL_URL` – Omniroute base URL (e.g., `http://172.16.1.110:10005/v1/chat/completions`)
- `LOCAL_SERVER_NAME` – Display name (slugified for Pi provider key; used as `name` in Copilot config)
- `LOCAL_API_KEY` – API key or `${input:...}` reference
- `OMNIROUTE_URL` – (Optional) URL for `--fetch` mode
