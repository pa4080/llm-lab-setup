# LLM Home Lab

_My home lab for LLMs, running on a single Nvidia RTX 3090 24GB GPU._

Folder structure:

```bash
llm-lab/
├── llama-cpp/          # LLaMA.cpp Docker-compose Setup with entrypoint `serve.sh`
├── scripts/            # Helper scripts that process `llama-cpp/router` files and other utilities
├── huggingface/        # Link to the models directory
├── confs/              # Configuration files for VSCode Copilot Chat, generated by `serve.sh`
|
├── docs/               # Some notes
├── llama-cpp-bull/     # Buun.LLaMA.cpp playground
├── sglang/             # SGLang playground
```


## Hardware

- GPU: Nvidia RTX 3090 24GB
- CPU: AMD Ryzen 9 5900
- RAM: 64GB DDR4
- ProxMox VM with Ubuntu 24.04

### Hugging Face

Download model:

```bash
hf download deepreinforce-ai/Ornith-1.0-9B-GGUF --local-dir deepreinforce-ai/Ornith-1.0-9B-GGUF  --include "**"
```

Download dataset:

```bash
hf download --repo-type dataset spiritbuun/turboquant-tcq-kv-cache --local-dir spiritbuun/turboquant-tcq-kv-cache
```
